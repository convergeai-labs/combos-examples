# 《灰烬王座 Ash Throne》— Plan Goal

> 一句话:环形废墟王座厅里,一场完整的有三阶段的魂系 Boss 决斗—— cinematic 开场、锁定视角、无敌帧翻滚、处决慢镜头;一局 3-5 分钟,这是"大作感"的展示品,不是又一个小游戏。

## 模型与资源指定

- 必须使用最强模型创建(创建参数指定 selected_chat_model_key,推理档拉满 reasoning_effort=max)。
- 不计迭代成本,但保持有界 turn 纪律:一次一个连贯改动,改完重新部署再验证。

## 传播设计(先于玩法)

- 完播率钩子:Boss 三阶段变身与处决慢镜头都在后段;通关时间留到结算。
- 反直觉难度钩子:魂系难度 = "0.1% 通关率"式分享;死亡画面本身有梗("YOU DIED"式呈现,用原创文案,不用注册商标原文)。
- 自我证明钩子:通关时间 + 无伤称号 = 可晒成绩单;"我 2:47 无伤了,你呢"。
- 失败集锦钩子:被 Boss 连招击飞的死亡镜头适合剪辑。

## Player fantasy & core loop

- 玩家幻想:你是挑战灰烬王的最后一个骑士。大作出场感、真实的攻防博弈、赢一次能吹一周。
- 核心循环:观察 Boss 前摇 → 翻滚闪避(无敌帧)→ 抓后摇输出 → 阶段转换 → 处决/被处决 → 结算。
- 冲突:Boss 大开大合但招招致命;玩家的资源是时机判断。回报:阶段压制的爽感 + 通关称号。

## Platform & input

- 竖屏 portrait 9:16 优先,Mobile + PC。
- 移动:左侧虚拟摇杆;右侧两个大按钮:翻滚 / 攻击(长按攻击=重击)。PC:WASD + Space 翻滚 + J/左键攻击(长按重击)。
- 软锁定镜头:始终面向 Boss,跟随平滑。

## 内容结构

- 一座竞技场:环形废墟王座厅,断裂石柱、地面裂缝、灰烬粒子、顶部体积光束。
- 一个 Boss:灰烬王(巨型铠甲骑士,持巨剑),HP 三格,三个阶段:
  - P1(100-66%):慢速巨剑三连劈、前冲突刺。前摇明显。
  - P2(66-33%):王座崩塌演出,场地边缘着火缩圈;新增横扫回旋、跳劈砸地(地面冲击波环)。
  - P3(33-0%):灰烬王燃烧形态,攻速加快,新增灰烬风暴(全屏粒子+随机落点轰炸);血量 10% 时进入可处决硬直。
- 玩家:HP 100,翻滚 0.4s 无敌帧,轻击 8 伤害快节奏,重击 22 伤害带前摇;受击有击退和短暂无敌。

## State machine

cinematic 标题(镜头环绕王座厅,标题浮现,"挑战灰烬王")→ 开战演出(Boss 起身,血条浮现带名字)→ 战斗(P1→P2→P3,阶段转换有演出)→ 胜利(处决慢镜头+定格)/ 失败(死亡画面,缓慢灰度)→ 结算卡(通关时间/死亡数/无伤称号)→ 再来一次。静音开关常驻;死亡后可立即重开。

## 结算卡(传播核心)

- 大字通关时间 + 称号(无伤="灰烬终结者",死亡≤3="弑君者",通关="幸存者")+ 死亡数 + "你敢挑战灰烬王吗" CTA。可保存为图。

## Visual / audio direction

- 风格:黑暗奇幻大作感。Three.js;PBR 材质;体积光与雾;灰烬/火星粒子;rim light; hit-stop(命中顿帧 60-90ms);屏幕震动;完美翻滚(在敌人攻击命中帧内翻滚)出白色火花 + 慢半拍子弹时间 0.3s。
- 角色:程序化低多边形骑士/Boss(无外部模型),但用布料/发光材质/动画状态机做出大作感;Boss 巨剑拖尾光效。
- WebAudio 合成:低音鼓点战斗 loop、剑风、命中金属声、阶段转换的钟声、死亡的低音衰减。静音开关常驻。

## Fairness / performance / acceptance gates

- 不变量:翻滚无敌帧恒定 0.4s;Boss 每招前摇 ≥0.5s 且视觉可辨;P3 落点轰炸有地面预警圈;无死锁(Boss/玩家卡进几何体自动推出);玩家 HP 归零必进死亡态;Boss HP 归零必进处决。
- 目标 60fps,移动端降级(粒子减半、阴影降档)后 ≥30fps;首屏 3s 内可交互。
- 验收门禁(每轮迭代后必查):
  1. 新 hash 出现;
  2. 全状态机走通:标题 → 三阶段 → 胜利与失败两分支 → 再来一次;
  3. 控制台/pageerror 零未解释错误;
  4. 390×844 与 1440×900 无重叠裁切,虚拟摇杆与按钮不遮关键视野;
  5. 移动(摇杆/WASD)、翻滚、轻重攻击在 touch 与 click/键盘都生效;
  6. 结算卡要素齐全(时间/称号/死亡数/CTA);
  7. Boss 三阶段招式各有可观测差异;玩家无伤病通关在机制上可行(允许很难,不许不可能);
  8. 处决慢镜头与死亡画面都可到达。

## Explicit exclusions

- 不做:账号、排行榜后端、多人、内购、第二把武器/装备系统、开放世界、存档、第二 Boss。
- 不使用任何外部模型/贴图/音频文件;不使用"YOU DIED"等注册商标原文文案;不声称与任何商业游戏有关。
