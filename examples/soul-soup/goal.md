# 《灵魂汤底》— Plan Goal

> 一句话:雨夜便利店里做 3 个温柔的选择(选食材/选座位/选一句话),结尾揭晓"你的灵魂是哪种汤"水彩人格卡;一局 40 秒,传播点是"你是什么汤"@朋友。

## 传播设计(先于玩法)

- 完播率钩子:汤底人格揭晓在最后一帧;水彩渐显动画留人。
- 评论区钩子:人格测试永动机——"我是番茄浓汤,热烈的疯子,谁懂";@朋友来测。
- 真人钩子(无相机版):每张人格卡配一句今晚限定文案,截图即状态签名。
- 诚实声明:结算卡常驻"娱乐向测试,不构成心理学诊断"。

## Player fantasy & core loop

- 玩家幻想:深夜被温柔对待的 40 秒;雨声、暖光、一碗汤。
- 核心循环:读场景 → 3 选 1 ×3 → 汤底揭晓 → 人格卡 → 再熬一锅。
- 冲突:无失败,只有"更了解自己一点"。回报:水彩人格卡。

## Platform & input

- 竖屏 portrait 9:16,Mobile + PC。
- 输入只有:点选选项卡片(每步 3 选 1)。

## 内容结构

- 3 步选择:① 深夜进店,先拿什么(番茄/豆腐/菌菇);② 坐在哪(窗边看雨/吧台角落/暖炉旁);③ 店员问"今天还好吗",你答(还行/不想说/今天很棒)。
- 27 条路径映射到 6 种汤底人格,每种有名字+一句判词+一段今晚文案:番茄浓汤(热烈的赤子)、菌菇慢炖(安静的根系)、味噌汤(安定的日常主义者)、冬阴功(酸辣的冒险家)、奶油玉米汤(被宠爱的孩子)、白粥(返璞归真的高手)。
- 映射规则:三个选项各带向量,加总取最近汤底;每条路径有确定结果(可复现);6 汤底在 27 路径中分布尽量均匀(每种 ≥3 条路径)。

## State machine

标题(灵魂汤底 / 雨夜,进来坐坐)→ 场景 1 → 场景 2 → 场景 3 → 熬煮演出(1.5s,锅里冒热气)→ 人格卡揭晓 → 再熬一锅/回标题。进度(第几步)与静音开关常驻。

## 结算卡(传播核心)

- 水彩人格卡:大字汤底名+称号,中部水彩汤碗插画(程序生成,各汤底配色不同),下部判词+今晚文案+诚实声明。
- 可保存为图;文案区适合直接当社交状态签名。

## Visual / audio direction

- 风格:暖彩水彩绘本。雨夜蓝紫远景+便利店暖橙光,水彩边缘晕染笔触,纸张颗粒,圆角手绘 UI;字体用圆体/手写感系统字体栈。
- 无外部素材;WebAudio 合成:雨声底噪、风铃一声、熬煮咕嘟声、揭晓暖和弦。静音开关常驻。

## Fairness / performance / acceptance gates

- 不变量:27 条路径全覆盖且结果确定;无死路;每步必有 3 个可点选项;人格卡 6 要素齐全。
- 60fps,首屏 3s 内可交互。
- 验收门禁:1. 新 hash 出现;2. 状态机全走通(抽查 ≥6 条不同路径到不同汤底);3. 控制台/pageerror 零未解释错误;4. 390×844 与 1440×900 无重叠裁切;5. touch 与 click 都生效;6. 结算卡要素齐全(汤名/称号/插画/判词/今晚文案/声明);7. 6 种汤底分布达标。

## Explicit exclusions

- 不做:账号、后端存档、多人、内购、更多章节、相机。
- 不声称心理学效度;不用任何真实品牌/店铺素材。
