## 传播设计落点

- **完播率**:答案在交互后揭晓+梗判词("三条项目符号加'总的来说',是 GPT 的经典整理术")
- **评论区站队**:题目有争议性,判词给"梗依据",观众可争论"这语气绝对是 Claude"
- **认知失调**:后 2 题模仿题("它学会了穿别人的衣服"机制),实测 2/5 —— 称号"概率学大师"自带嘲讽
- **诚实声明**:全屏常驻"题目为风格演绎,非真实模型输出"(IP 底线,不误导)
- **自拍战绩海报(v4 起,传播核心)**:结算卡【拍张照,生成战绩海报】→ 自拍进像素相框 + 战绩 + 称号 + "不服?@你朋友来测" 合成 720×1280 竖版图,长按/按钮本地保存;三级降级(摄像头→相册→默认像素头像)保证人人可出图
- **全程出镜模式(v5 起)**:标题页可选【📷 开启出镜模式】→ 右上角常驻镜像自拍窗,贯穿答题→揭晓→结算——录屏/直播时真人表情就是内容本身(答题时纠结、答错时崩溃),短视频游戏的主流形态;海报直接抓实时流的帧,不重复要权限
- **蹭热点引擎**:新模型发布 = 题库加新考生/新题

**"点了没反应"根因与修复(4e1012d4 → 356eea59,真实用户实测反馈驱动)**:
- 根因:getUserMedia 在权限弹窗被关掉/忽略、或微信/抖音 WebView 不弹框时 promise 永远 pending(不 resolve 也不 reject),原实现裸 await 无超时无加载态 → 点击后界面零反馈;iframe 权限(创作台 iframe 有 allow="camera")和网络均排除
- 修复:点击即加载态"正在请求摄像头权限…"+防重复点击;8 秒 Promise.race 超时;超时→"摄像头没反应?请检查地址栏权限图标,或换系统浏览器打开(微信/抖音内置浏览器可能拦截)";NotAllowedError→"权限被拒绝:点地址栏左侧图标重置权限,或用相册";两文案均带【从相册选一张生成海报】【知道了】出口;超时后迟到的流立即 stop 防后台占用
- 二轮修复:引导文案从 ~2 秒自动消失改为驻留至用户主动 dismiss(实测 timeline:0.5s 加载态 → 8.3s 引导 → 10.5s 消失,用户来不及读)
- 最终验证(356eea59):pending 场景引导驻留 24s+ 不失、【知道了】恢复可重试 ✓;拒权文案+相册出口+file input ✓;成功路径回归(开启→自拍窗→答题常驻)✓;控制台 0 错误 ✓
