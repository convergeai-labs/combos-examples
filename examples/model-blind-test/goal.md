# 《模型盲测 Model Blind Test》— Plan Goal

> 看一段回答,猜是哪个 AI 模型写的。5 题一轮,第 4 题开始没人能全对。答案揭晓自带梗解说,评论区先吵起来。

## 传播设计(先于玩法)

- **完播率钩子**:每题答案在交互后揭晓+一句梗判词;视频形态=出题→留白 3 秒(观众弹幕猜)→揭晓。
- **评论区钩子**:题目本身有争议性("这语气绝对是 Claude"),观众互相争论=真 PK。
- **认知失调钩子**:第 4-5 题是"模仿题"(一个模型模仿另一个的文风),错误率设计 80%+,猜错→"我居然被骗了"→转发拉朋友下水。
- **诚实声明**:结算页常驻一行小字"题目为风格演绎,非真实模型输出"——图一乐,不误导。这是 IP 底线。

## Player fantasy & core loop

- 玩家幻想:你是"AI 懂哥",自称一眼能看穿各家模型的文风。游戏给你 5 次证明自己的机会。
- 核心循环:读题(一个 prompt + 一段回答)→ 10 秒内点选 4 个模型之一 → 揭晓对错+梗判词 → 下一题 → 5 题结束出战绩卡。
- 冲突:倒计时压力 + 后段题目故意迷惑。
- 回报:称号+击败百分比+错题回顾;一键再来一轮。

## Platform & input

- 竖屏 portrait 9:16,Mobile + PC,2d_canvas 单场景。
- 操作只有点选:4 个大按钮(GPT 绿 / Claude 橙 / Gemini 蓝 / DeepSeek 紫),不用官方 logo,纯文字+主题色。
- 每题 10s 倒计时,超时算答错(判词:"犹豫就会败北")。

## 题目结构(题库 15 题,每轮随机抽 5,前 2 易、第 3 中、后 2 难)

每题 = { prompt, answer_text, correct_model, 判词, difficulty }。

文风刻板印象(梗依据,判词要点题):
- **GPT**: 结构化强迫症,爱 bullet 和"总的来说",滴水不漏的正确废话。
- **Claude**: 严谨长文,先夸问题好("这是个有趣的问题"),爱加 caveat 和免责。
- **Gemini**: 快人快语,爱扯实时信息和多模态联想,偶尔答非所问。
- **DeepSeek**: 直给干货,不装,偶尔蹦出中文互联网梗,性价比气质。

难题(第 4-5 题)用"模仿题":例如一段 bullet 结构严谨文,开头却是"这是个有趣的问题"——正确答案 Claude 学了 GPT 的形,判词:"它学会了穿别人的衣服"。

题库示例(完整题库由 Boo 生成 15 题,含判词):
1. prompt:"用一句话推荐周末去哪玩" / 回答:先列 3 个 bullet 再"综上所述" → GPT(易)
2. 回答开头"这是个很有趣的问题!不过在回答之前,我需要说明……" → Claude(易)
3. 回答带"刚刚看到热搜……"的实时联想 → Gemini(中)
4. 模仿题:bullet 结构 + Claude 开头 → Claude(难)
5. 模仿题:简短直给 + "总的来说" → GPT 模仿 DeepSeek(难)

## State machine

标题(logo+"你能看穿 AI 吗?"+开始) → 题目(题号 i/5 + 倒计时环 + prompt + 回答卡片 + 4 选按钮) → 揭晓(对/错大字 + 判词 + 1.8s 自动下一题) → … → 结算卡 → 再来一轮/回标题。暂停常驻。

## 结算卡(传播核心)

- 大字战绩:"5 题对 3 —— AI 懂哥" / "5 题对 1 —— 你已被 AI 骗过"
- 称号梯度:5=AI 鉴定师 / 4=AI 懂哥 / 3=略懂略懂 / 2=概率学大师 / 0-1=你已被 AI 骗过
- "击败了全国 X% 的人"(伪随机 60-99%,低分反向嘲讽"击败了全国 8% 的人")
- 错题回顾一行一条:"第4题:你选 GPT,其实是 Claude —— 它学会了穿别人的衣服"
- CTA:"不服?@你朋友来测" + 诚实声明小字

## Visual / audio direction

- 像素风延续 Model Brawl 视觉语言(深色底+四色主题),回答卡片做成"终端窗口"样式(等宽字体+光标),模型按钮=四色大牌。
- 揭晓瞬间:答对绿闪+音效升调;答错红震+下坠音;第 4-5 题揭晓时卡片"撕掉伪装"小动画(回答文本抖一下换色)。
- 倒计时环在卡片顶部,最后 3s 变红脉冲。
- WebAudio 合成音效,静音开关常驻;无外部素材,全程序化。

## Fairness / performance / acceptance gates

- 随机抽题:15 题池每轮不放回抽 5,难度位置固定(易易中难难);同一轮不重复。
- 判词必须点出梗依据,不允许"答案是 X,因为它就是 X"这种废话。
- 60fps,首屏 3s 内可交互。
- 验收门禁(每轮迭代后必查):
  1. 新版本 hash 出现;
  2. 标题→答题×5→结算→再来一轮 全状态走通(故意答错和全对两条路径);
  3. 控制台/pageerror 零未解释错误;
  4. 390x844 与 1440x900 无重叠裁切;
  5. 点选在 touch 与 click 都生效(视觉坐标);
  6. 结算卡完整:战绩+称号+击败百分比+错题回顾+CTA+诚实声明;
  7. 超时路径验证(不点 10s 自动判错)。

## Explicit exclusions

- 不做:真模型 API 调用(静态题库)、账号、排行榜后端、多人、真"全国排名"(击败百分比为伪随机演出)。
- 不使用任何厂商官方 logo/商标;不声称题目是真实模型输出。
