# 《崩塌实验室 Crash Lab》— Plan Goal

> 一句话:拖动静止的钢球瞄准,松手发射,把影棚中央一座精致的 3D 玻璃塔轰成慢动作碎片,按破坏率结算评级;一局 20 秒,传播点是 Blender 级渲染感的坍塌美学。

## 模型指定

- 本项目必须使用 gpt-6-astra 模型构建(用户指定,用于验证该模型的 3D 大作能力上限)。

## 传播设计(先于玩法)

- 完播率钩子:坍塌全程慢动作,破坏率%和评级在最后一帧揭晓。
- 解压 ASMR 钩子:玻璃连续碎裂 + 低音乐器共振,视觉粒子与声效同步,是天然的解压素材。
- 失败集锦钩子:差 1% 没倒干净的"悬在那一块砖"是评论区素材("那一块砖是承重墙吗")。
- 自我证明钩子:"我 98.7%,你能一击全清吗"——破坏率天然可比较。

## Player fantasy & core loop

- 玩家幻想:好莱坞特效总监,一次完美爆破。
- 核心循环:拖动瞄准(轨迹预览)→ 松手发射 → 慢动作坍塌 → 破坏率评级 → 再来一次/下一座结构。
- 冲突:一发定乾坤,没有第二球。回报:坍塌奇观 + 破坏率数字。

## Platform & input

- 竖屏 portrait 9:16,Mobile + PC。
- 输入只有一个:按住拖动瞄准(显示弹道虚线),松手发射。

## 内容结构

- 3 种结构轮换:玻璃塔(12 层,脆)、砖墙(带拱,重)、多米诺阵(连锁导向)。
- 每局随机抽一种结构,物理模拟用固定种子(同弹道必得同破坏率 ±5%)。
- 评级梯度:0-20% 挠痒痒 / 20-50% 拆迁实习生 / 50-80% 爆破专家 / 80-95% 末日工程师 / 95%+ 完美一击 PERFECT。

## State machine

标题(崩塌实验室 / 一击,全碎)→ 瞄准(结构全景缓慢环绕镜头,拖动弹道预览)→ 发射(0.3s 常速)→ 慢动作坍塌(0.25× 速度,4-6s,镜头推近)→ 结算卡(破坏率% + 评级 + 结构名)→ 慢动作回放 / 再来一次 / 回标题。静音开关常驻。

## 结算卡(传播核心)

- 大字破坏率%(如 98.7%)+ 评级称号 + 坍塌最美一帧做背景 + "你能一击全清吗"CTA。
- 可保存为图。

## Visual / audio direction

- 风格:Blender Cycles 渲染感。PBR 材质(玻璃折射、砖块粗糙度、金属球高光)、三点布光 + 柔和阴影、浅景深、暖灰影棚背景、坍塌时的体积尘埃粒子、轻微镜头呼吸感。
- 用 Three.js + 轻量物理(cannon-es 或自写简化刚体);所有材质程序化生成,无外部素材;低端机降级(粒子数减半、关景深)。
- WebAudio 合成:玻璃碎裂(高频颗粒)、砖块碰撞(低通噪声)、慢动作时的音高下沉。静音开关常驻。

## Fairness / performance / acceptance gates

- 不变量:固定种子下同弹道破坏率偏差 ≤5%;无球卡死穿模出界(超时 8s 强制结算);60fps 目标,低端降级后 ≥30fps。
- 首屏 3s 内可交互。
- 验收门禁(每轮迭代后必查):1. 新 hash 出现;2. 状态机全走通(含超时强制结算分支);3. 控制台/pageerror 零未解释错误;4. 390×844 与 1440×900 无重叠裁切;5. 拖动瞄准与发射在 touch 与 mouse 都生效;6. 结算卡要素齐全(破坏率/评级/结构名/CTA);7. 同一坐标重放两次,破坏率一致。

## Explicit exclusions

- 不做:账号、排行榜后端、多人、内购、关卡编辑器、第二球。
- 不使用任何外部模型/贴图文件;不声称真实物理引擎精度。
