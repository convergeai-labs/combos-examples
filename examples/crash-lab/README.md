# 崩塌实验室 Crash Lab

> Blender 级渲染感的 3D 物理破坏:拖动瞄准,松手发射钢球,看影棚中央的 3D 结构在 0.25× 慢动作里崩解,按破坏率% 评级。一局 20 秒。

![实玩:瞄准 → 发射 → 慢动作坍塌 → 69.4% 结算](../../docs/assets/demo-crashlab.gif)

## 为什么这个例子重要

- **合集里第一个 3D 游戏**:PBR 材质、三点布光、浅景深、体积尘埃——Blender Cycles 渲染方向全部程序化落地,无外部素材。
- **指定模型构建**:全程由 **gpt-6-astra** 模型一次构建(`selected_chat_model_key` 可审计),0 修复 turn。
- **物理确定性**:固定种子,同弹道同破坏率——验收时同一拖动两次实测 ±0%(100%/100%)。
- **输入维度**:压敏式拖放(方向+力度),与合集中画(轨迹)/点(时机)/选(分支)互补。
