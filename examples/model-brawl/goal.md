# 《模型大乱斗 Model Brawl》— Plan Goal

> One-button AI-model fighting game. 20-second rounds. Every round produces a clip-worthy KO moment.

## Player fantasy & core loop

- 玩家幻想:你是挑战者,操纵自己喜欢的 AI 模型,在武道馆里把其他大模型打趴下。
- 核心循环:选角色 → 20 秒一局对打(一键出拳/连点 combo/大招)→ KO 或读秒判定 → 结算卡(胜负+梗文案)→ 秒重开或换对手。
- 冲突:对手 AI 自动进攻与格挡,节奏越来越快;玩家血量与蓝条管理。
- 风险:被 KO 就输,读秒时血量低者输。
- 回报:KO 慢镜头 + 搞笑结算卡 + 连胜计数。

## Platform & input

- 竖屏 portrait 9:16,Mobile + PC(PC 用鼠标/空格/点击,移动端 tap)。
- 模板 2d_canvas,Canvas 渲染,单场景。
- 操作(只有一个动作维度):
  - 点按/点击 = 轻拳(快,小伤害)
  - 快速连点 = combo 三连击(第三拳大伤害+击退)
  - 蓝条满时点按大招按钮 = 必杀(大伤害+全屏特效+慢镜头)
- 蓝条(算力条)随时间与受击积累,必杀的释放时机是唯一决策点。

## Roster(4 个角色,原创像素小人,不用官方 logo)

| 角色 | 主题色 | 梗数值(直接展示在选人页) | 性格动作 |
|---|---|---|---|
| GPT | 绿 | 攻击★★★ 血★★★ 速度★★★ "六边形战士,但贵" | 稳重直拳 |
| Claude | 橙 | 攻击★★ 血★★★★ 速度★★★ "血厚,上下文长" | 太极推手风 |
| Gemini | 蓝 | 攻击★★★ 血★★ 速度★★★★ "快但脆" | 快速连段 |
| DeepSeek | 紫 | 攻击★★★★ 血★★ 速度★★★ "价格屠夫,性价比之王" | 爆发重击 |

数值必须实战平衡:任何角色对任何角色胜率都应可达,差距来自玩家操作而非数值碾压。读秒判定按剩余血量百分比。

## State machine

标题(logo+开始) → 选人(玩家)→ 选对手(随机/指定)→ 战斗(20s 倒计时,双方血条+蓝条+倒计时大字) → KO 慢镜头(或读秒判定)→ 结算卡 → 重开/换对手/回标题。暂停按钮常驻。

## 结算卡(传播核心)

- 大字结果:"Claude KO GPT!"或"读秒判定:DeepSeek 险胜!"
- 梗文案池(随机一条),例:"跑分没输过,打架没赢过" / "价格屠夫名不虚传" / "上下文太长,闪避太慢" / "这一拳 65k token 的功力"
- 连胜计数 + "不服?换你来" 行动号召
- 结算卡本身是 Canvas 绘制、可长按保存的一张完整图(含角色立绘),这是分享素材。

## Visual / audio direction

- 像素风 chibi 格斗小人(大头二头身),纯色主题色+白色武道服,无商标元素。
- 场景:像素武道馆,深色地板+聚光灯,观众席剪影随出拳欢呼摆动。
- 打击感:出拳白闪+屏幕微震+打击粒子;KO 时 0.3s 慢镜头+灰度+大字 "K.O."。
- 音效:拳声、combo 升调、必杀蓄力、KO 重音、观众欢呼;BGM 8-bit 格斗循环。无音频文件时用 WebAudio 合成,保留静音开关。
- 素材全部异步加载 + 程序化 fallback(色块小人),任何素材失败游戏仍可玩。

## Fairness / performance / acceptance gates

- 对手 AI:有进攻/格挡/后退节奏,前 3 秒温和(教学窗口),逐局小幅增强;不读玩家输入帧。
- 60fps 预算:粒子与观众数量自适应降级;首屏 3s 内可交互。
- 验收门禁(每次迭代后必查):
  1. ListVersions 出现新版本 + random hex;
  2. direct-play URL 打开,标题/选人/战斗/KO/结算/重开全状态走通;
  3. 控制台与 pageerror 零未解释错误;
  4. 390x844 与 1440x900 无重叠裁切;
  5. 一键操作在移动端 touch 与 PC 点击都生效;
  6. 结算卡完整可读、含胜负与梗文案;
  7. 素材请求成功,失败时 fallback 生效。

## Explicit exclusions

- 不做:排行榜后端、账号系统、多人对战、内购、更多角色(本迭代)、剧情模式。
- 不使用任何厂商官方 logo 或商标图;角色名仅用文字。
