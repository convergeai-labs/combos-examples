# 《一笔签》— Plan Goal

> 一句话:玩家在宣纸上自由画一笔,墨迹实时晕染,提笔生成一张独一无二的"2026 水墨运势签"海报;一局 30 秒,传播点是每张签都因你的笔迹而不同。

## 传播设计(先于玩法)

- 完播率钩子:墨迹晕染动画 → 关键字揭晓在最后一拍。
- 评论区钩子:"我抽出的是『躺』,你呢"——签文有争议空间(有人抽到"卷",有人抽到"躺")。
- 自我证明/UGC 钩子:每张签的墨形来自玩家真实笔迹,不可复制,天然晒图素材。
- 诚实声明:结算卡常驻小字"签文为程序生成的娱乐内容"。

## Player fantasy & core loop

- 玩家幻想:禅意、治愈、东方仪式感——像在庙里求签,但签是你自己画的。
- 核心循环:静心画一笔 → 墨晕染开 → 关键字+签诗揭晓 → 保存海报 → 再抽一次。
- 冲突:无对抗,冲突来自"这一笔会抽出什么"。回报:专属水墨签海报。

## Platform & input

- 竖屏 portrait 9:16,Mobile + PC。
- 输入只有一个:按住并拖动,画一笔(连续轨迹);提笔即完成。

## 内容结构

- 关键字池 ≥12 个,覆盖情绪光谱:卷 / 躺 / 燃 / 稳 / 浪 / 悟 / 甜 / 野 / 静 / 破 / 圆 / 光。
- 每个关键字配一句七言签诗(原创,古风,不许抄袭真实签文/诗句)。
- 抽签映射由笔迹特征决定(笔画长度、平均速度、转折数、覆盖率),同一笔迹必得同一签(可复现);不同笔迹落不同签。

## State machine

标题(一笔签 / 画一笔,抽你的 2026)→ 绘画(宣纸底,笔触墨色,伴研磨声)→ 晕染演出(1.5s,墨扩散+纸纹浮现)→ 结算签(大字关键字+签诗+笔迹墨形+朱砂印章+诚实声明)→ 再抽一次/回标题。静音开关常驻。

## 结算卡(传播核心)

- 竖版水墨海报:上部大字关键字(书法感字体),中部玩家笔迹墨形艺术化重绘,下部签诗+朱砂圆印"一笔签"+诚实声明小字。
- 支持长按/按钮保存为图。

## Visual / audio direction

- 风格:国风水墨。米白宣纸底(程序生成纸纹),墨色笔触带飞白与晕染(径向渐变+噪声扩散),朱砂红印章点缀,竖排文字。
- 无外部素材;WebAudio 合成:研磨声/笔触沙沙/揭晓时一声木鱼。静音开关常驻。

## Fairness / performance / acceptance gates

- 不变量:任意笔迹必得签(空笔迹提示"画一笔再提笔");同一轨迹重放得同签;12 签分布无系统性偏斜(模拟 1000 次随机轨迹,每签出现率 3%-15%)。
- 60fps,首屏 3s 内可交互。
- 验收门禁:1. 新 hash 出现;2. 状态机全走通(含空笔迹分支);3. 控制台/pageerror 零未解释错误;4. 390×844 与 1440×900 无重叠裁切;5. 绘画在 touch 与 mouse 都生效;6. 结算卡要素齐全(关键字/签诗/墨形/印章/声明);7. 1000 次模拟分布达标。

## Explicit exclusions

- 不做:账号、排行榜后端、多人、内购、真实解签/命理声称、相机。
- 不使用任何外部图片/字体文件;不声称签文有预测效力。
