# 毫秒反应局 Millisecond Reaction

> 霓虹合成波:信号灯变绿瞬间点击,5 轮取平均毫秒数,生成反应段位卡。一局 45 秒。

![实玩:等灯 → 变绿点击 → 毫秒成绩](../../docs/assets/demo-ms-reflex.gif)

## 为什么这个例子重要

- **输入维度**:单发时机(毫秒级),和画(连续)/选(离散)互补。
- **成绩引战结构**:毫秒数天然可比较,"我 187ms,你呢"自带评论区战火;抢跑红屏是失败集锦素材。
- **WebGL 验证案例**:游戏用 WebGL 渲染(canvas 无 2d context),验证方改用截图像素判定(ffmpeg 1px RGB 探针)识别变绿时刻——像素级外部证据,不依赖游戏内部状态。
