# 《毫秒反应局》— Plan Goal

> 一句话:霓虹夜幕下等灯变绿,变色瞬间点击,5 轮取平均毫秒数,生成"反应段位卡";一局 45 秒,传播点是晒成绩引战。

## 传播设计(先于玩法)

- 完播率钩子:每一轮的等待-变色-点击天然是悬念节拍;结算的平均毫秒数留到最后。
- 评论区钩子:"我 187ms,有对手吗"——毫秒数天然引战;段位动物(猎豹/人类/树懒)自带梗。
- 认知失调钩子:越急越抢跑,抢跑红屏"TOO SOON"——失败集锦友好。
- 诚实声明:结算卡常驻"超过 X% 玩家为演出效果,非真实排行榜"。

## Player fantasy & core loop

- 玩家幻想:电竞选手级的反应自证;霓虹赛博夜里的肾上腺素。
- 核心循环:等(随机 1.5-4s 红灯)→ 变绿瞬间点击 → 毫秒飘字 → 下一轮 → 5 轮结算。
- 冲突:人与自己的预判冲动对抗;抢跑即该轮判 999ms 罚时。回报:毫秒成绩+段位。

## Platform & input

- 竖屏 portrait 9:16,Mobile + PC。
- 输入只有一个:点击/触屏(全屏任意位置)。红灯期点击=抢跑。

## 内容结构

- 5 轮一局,等待时间随机 1.5-4.0s 均匀分布;第 3/4 轮穿插一次"假动作"(闪烁黄灯 0.4s 不变绿,点了算抢跑),第 5 轮等待时间加长(2.5-5s)制造终局张力。
- 段位梯度(按平均 ms):<200 闪电侠 / 200-240 猎豹 / 240-290 人类精英 / 290-350 普通人类 / 350-450 树懒 / >450 或含抢跑 2 次以上 梦游者。

## State machine

标题(毫秒反应局 / 灯绿就点)→ 轮次(红灯等待 → 绿灯点击 → 成绩飘字;抢跑 → TOO SOON 红屏 0.8s 后进下一轮)→ 5 轮后结算段位卡 → 再来一局/回标题。轮次指示(1/5..5/5)与静音开关常驻。

## 结算卡(传播核心)

- 霓虹段位海报:大字平均毫秒数、段位动物名+称号、5 轮逐轮条形图、"超过 X% 玩家"(标注演出)、底部"不服来测"CTA。
- 可保存为图。

## Visual / audio direction

- 风格:霓虹合成波。深紫夜空、透视霓虹网格地面、复古落日、CRT 扫描线、辉光 bloom;灯=巨大圆形信号灯,红/绿/黄三色高饱和发光。
- 无外部素材;WebAudio 合成:等待低频脉冲、变绿"叮"、点击确认音、抢跑蜂鸣、结算 synth 和弦。静音开关常驻。

## Fairness / performance / acceptance gates

- 不变量:计时用 performance.now() 且以变色渲染帧为起点(不得用 setTimeout 估算);抢跑判定与显示一致;5 轮必定结束;成绩如实显示测量值(只允许百分比是演出,毫秒必须为真)。
- 60fps,首屏 3s 内可交互。
- 验收门禁:1. 新 hash 出现;2. 状态机全走通(含抢跑分支与假动作轮);3. 控制台/pageerror 零未解释错误;4. 390×844 与 1440×900 无重叠裁切;5. touch 与 click 都生效且计时一致;6. 结算卡要素齐全(毫秒/段位/逐轮图/百分比+演出标注/CTA);7. 假动作轮点击正确判抢跑。

## Explicit exclusions

- 不做:账号、真实排行榜后端、多人对战、内购、更多关卡。
- 不声称毫秒数为医学/电竞认证;"超过 X% 玩家"必须带演出标注。
